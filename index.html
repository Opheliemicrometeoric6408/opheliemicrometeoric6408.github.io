  4. Once the download finishes, find the downloaded file in your Downloads folder.
  5. Extract the contents of the zip file by right-clicking and selecting "Extract All" (Windows) or double-clicking (Mac).

💻 Running with Docker (for Homelab Enthusiasts)

If you're the self-hosted type, here's how to run it with Docker. This is completely optional - the simple HTML file works perfectly too.

Create a folder somewhere (like ~/slideshow) and put all your photos inside. Then run this command:

docker run -d -p 8080:80 -v your_photos_folder:/usr/share/nginx/html:ro --name ios9-slideshow nginx:alpine

Now open your browser to http://your-server-ip:8080. That's it - your slideshow is live!

🔧 Configuration & Customization

Everyone loves a little customization. Here are common tweaks you can make without any coding knowledge:

  • Change slideshow speed: Open the slideshow.js file in a text editor (like Notepad). Look for a numeric value (default: 5000 milliseconds = seconds). Change it to any number you like (e.g., 3000 for 3 seconds).
  • Add a fade effect: Inside the same file, set fadeEffect to true instead of false.
  • Shufflephotos: Set shuffle to true for randomness. Perfect for memory walls!
  • Show captions: Name your photo files like Grand Canyon - 2021.jpg, and the caption appears at the bottom if you set showCaptions to true.

🛠️ Troubleshooting & FAQs

❓ My photos aren't showing up.

Make sure your photos are in the same folder as the index.html file. Also check they have common extensions like .jpg, .png, or .heic.Refresh the page completely (Ctrl+F5).

❓ The slideshow is too fast/slow.

Open slideshow.js in Notepad. Find interval: 5000 and change that number (milliseconds). Lower = faster, higher = slower. Save and refresh.

❓ Everything works but no transition effect.
